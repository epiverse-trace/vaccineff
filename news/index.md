### Breaking Changes

- **[`estimate_vaccineff()`](https://epiverse-trace.github.io/vaccineff/reference/estimate_vaccineff.md)**
  replaces `effectiveness()`.

  - It returns an object of class `vaccineff`.
  - The `at` parameter must always be provided for accurate results.

- **[`plot.vaccineff_data()`](https://epiverse-trace.github.io/vaccineff/reference/plot.vaccineff_data.md)**
  replaces
  [`plot_coverage()`](https://epiverse-trace.github.io/vaccineff/reference/plot_coverage.md).

- **`cohortdata`** has been simplified and reduced to improve examples
  and reduce computation time.

## vaccineff 0.0.4

### New Features

`{vaccineff 0.0.4}` simplifies data handling by using
[`linelist`](https://github.com/epiverse-trace/linelist) objects. Tags
are assigned to the outcome, censoring, and vaccine dates using the
function
[`make_vaccineff_data()`](https://epiverse-trace.github.io/vaccineff/reference/make_vaccineff_data.md),
reducing redundancy in function input parameters.

The new pipeline includes the following three functions and
complementary methods: `summary` and `plot`.

- **[`make_vaccineff_data()`](https://epiverse-trace.github.io/vaccineff/reference/make_vaccineff_data.md)**:
  This function returns an S3 object of the class `vaccineff_data()`
  with the study’s relevant information. It also allows the creation of
  a matched cohort to control for confounding variables by setting
  `match = TRUE` and passing the appropriate `exact` and `nearest`
  arguments. The method
  [`summary()`](https://rdrr.io/r/base/summary.html) can be used to
  check cohort characteristics, matching balance, and the sizes of
  matched, excluded, and removed populations.

- **[`plot_coverage()`](https://epiverse-trace.github.io/vaccineff/reference/plot_coverage.md)**:
  This function returns a plot of the vaccine coverage or cumulative
  coverage. If the population is matched, the plot includes the
  resulting count of doses after matching.

- **`effectiveness()`**: This function provides methods for estimating
  VE using the $`HR`$. A summary of the estimation is available via
  [`summary()`](https://rdrr.io/r/base/summary.html), and a graphical
  representation of the methodology is generated by
  [`plot()`](https://rdrr.io/r/graphics/plot.default.html).

### Breaking changes

The following functions are no longer accessible to users, but they are
called within
[`make_vaccineff_data()`](https://epiverse-trace.github.io/vaccineff/reference/make_vaccineff_data.md):

- [`make_immunization()`](https://epiverse-trace.github.io/vaccineff/reference/make_immunization.md)
- [`match_cohort()`](https://epiverse-trace.github.io/vaccineff/reference/match_cohort.md)

The [`plot()`](https://rdrr.io/r/graphics/plot.default.html) method
returns `log-log` and `survival` type plots when receiving an object of
type `effectiveness`. This deprecates the functions
[`plot_survival()`](https://epiverse-trace.github.io/vaccineff/reference/plot_survival.md)
and
[`plot_loglog()`](https://epiverse-trace.github.io/vaccineff/reference/plot_loglog.md).

## vaccineff 0.0.3

### New Features

This version introduces an iterative matching routine within
[`match_cohort()`](https://epiverse-trace.github.io/vaccineff/reference/match_cohort.md).
After adjusting the exposure times of the pairs, new pairs are created
between the removed ones and the unmatched population. The new matches
with inconsistent exposure times are removed again, and the procedure is
repeated until no new pairs can be made. The usage of all the functions
remains unchanged by this update.

## vaccineff 0.0.2

### New Features

The number of functions and steps for computing vaccine effectiveness
has been drastically reduced in `{vaccineff 0.0.2}`. The new pipeline
for estimation now consists of three main functions:

- **[`make_immunization()`](https://epiverse-trace.github.io/vaccineff/reference/make_immunization.md)**:
  Prepares information on immunization dates and vaccine status. It can
  handle multiple columns for vaccine dates and custom vaccine statuses.
  In such cases, it returns the name of the column selected as
  immunizing and the custom name, if provided.

- **[`match_cohort()`](https://epiverse-trace.github.io/vaccineff/reference/match_cohort.md)**:
  This function has been improved and generalized to reduce observation
  bias in cohorts. The default matching strategy is static, based on
  nearest and exact characteristics using Mahalanobis distance. The
  exposure times of the pairs are adjusted after matching. In future
  releases, rolling calendar matching will be introduced as a more
  accurate method to account for exposure times. The function returns an
  S3 object of class `match`, from which a summary and balance of the
  cohorts can be printed using the
  [`summary()`](https://rdrr.io/r/base/summary.html) method. The matched
  cohort can be extracted using the `get_dataset()` method. The matched
  cohort contains all the necessary information to estimate vaccine
  effectiveness.

- **`effectiveness()`**: Receives a (matched) cohort and estimates
  vaccine effectiveness using the Hazard Ratio (HR). An S3 object of
  class `effectiveness` is returned, compatible with the
  [`plot()`](https://rdrr.io/r/graphics/plot.default.html) and
  [`summary()`](https://rdrr.io/r/base/summary.html) methods. Future
  releases will provide relative risk (RR) as an alternative for cases
  where the proportional hazards assumption is not satisfied.

### Breaking Changes

The following functions are no longer accessible to users. However, they
are called within
[`make_immunization()`](https://epiverse-trace.github.io/vaccineff/reference/make_immunization.md):

- [`get_immunization_date()`](https://epiverse-trace.github.io/vaccineff/reference/get_immunization_date.md)
- [`get_immunization_dose()`](https://epiverse-trace.github.io/vaccineff/reference/get_immunization_dose.md)
- [`get_immunization_vaccine()`](https://epiverse-trace.github.io/vaccineff/reference/get_immunization_vaccine.md)
- [`set_status()`](https://epiverse-trace.github.io/vaccineff/reference/set_status.md)

Similarly, the `effectiveness()` function deprecates the use of
`coh_eff_noconf()`, and the
[`plot()`](https://rdrr.io/r/graphics/plot.default.html) method now
returns a log-log plot, replacing the
[`plot_loglog()`](https://epiverse-trace.github.io/vaccineff/reference/plot_loglog.md)
function.
